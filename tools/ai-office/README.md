# AI Office

Claude Code のセッションを **3D のオフィス** に並べて、リアルタイムに眺めるツールです。
セッション 1 つ = 社員 1 人。作業中はタイピング、承認待ちは手を挙げて赤い吹き出し、サブエージェントは小さな部下として現れます。スマホでも使えます（ドラッグで回転・ピンチで拡大・タップで選択、下の一覧から社員を選ぶこともできます）。

```
Claude セッション（クラウド/ローカル）
  └ hooks → hook/ai-office-hook.mjs ──POST /events──▶ server.mjs ──SSE /stream──▶ ブラウザ（three.js）
```

構成は [disler/claude-code-hooks-multi-agent-observability](https://github.com/disler/claude-code-hooks-multi-agent-observability)（hooks → サーバー → ストリーム → 画面）を参考にしています。同リポジトリはライセンス表記が無いため、コードは流用せず自作しています。

## まず試す（サーバー無しで見た目だけ）

```bash
cd tools/ai-office && npm install
AI_OFFICE_ALLOW_NO_TOKEN=1 npm start
# → http://localhost:8787/?demo=1  （疑似セッションが動きます）
```

## 本番の使い方（クラウドセッション中心）

クラウドセッションからはあなたの PC の localhost に届かないため、**インターネットから届く場所にサーバーを置く**必要があります。

### 1. サーバーを公開する

`Dockerfile` 付きなので、Render / Fly.io / Railway など Docker が動く所ならどこでも置けます（SSE は常時接続なので、サーバーレス型（Vercel Functions 等）は不向きです）。

| 環境変数 | 意味 |
|---|---|
| `AI_OFFICE_TOKEN` | **必須**。フックからの送信に使う合言葉。長いランダム文字列にする |
| `AI_OFFICE_VIEW_KEY` | 任意。設定すると閲覧にも `?key=...` が必要になる（推奨） |
| `PORT` | 待受ポート（既定 8787） |

スマホでは `https://<あなたのドメイン>/?key=<VIEW_KEY>` を開き、ホーム画面に追加しておくと便利です。

### 2. クラウド環境にシークレットを入れる

claude.ai の環境設定で、次の 2 つを環境変数に設定します。

- `AI_OFFICE_URL` … 例 `https://office.example.com`
- `AI_OFFICE_TOKEN` … 手順 1 と同じ値

あわせて **ネットワーク許可に、サーバーのホスト名を追加**してください（許可されていないと送信がブロックされます。フックは失敗しても Claude の作業は止めません）。

### 3. 各リポジトリにフックを入れる

1. `hook/ai-office-hook.mjs` を、対象リポジトリの `.claude/hooks/ai-office-hook.mjs` にコピーする
2. `settings.example.json` の `hooks` を、そのリポジトリの `.claude/settings.json` にマージする（既存の hooks がある場合は同じイベントの配列に追記）

これだけで、そのリポジトリのクラウドセッションが全部オフィスに出社します。ローカルの Claude Code でも同じ設定で動きます（`AI_OFFICE_URL` を環境変数に入れる）。

## 見え方

| 状態 | 見え方 |
|---|---|
| 作業中 | タイピング。吹き出しにツール（編集中 / 読み込み中 / 検索中 / コマンド実行…） |
| 承認待ち | 手を挙げて赤い吹き出し。スマホは振動、タブ名に `(N)` |
| 待機中 | 机でのんびり。周りを見回す |
| 無信号 | 15〜30 分イベントが無いと居眠り（Zzz）。3 時間で退社 |
| サブエージェント | 机の横に小さな部下（最大 4 人表示） |
| 出社 / 退社 | 玄関から歩いてきて席に着く。`SessionEnd` で玄関へ帰る |

机が足りなくなると部屋が奥へ広がります（最大 60 人）。

## プライバシー

フックが送るのは **イベント種別・ツール名・短い対象名（ファイル名、コマンドの 1 語目）・リポジトリ名・承認待ちの通知文**だけです。プロンプト本文、ファイルの中身、コマンド全文は送りません。`AI_OFFICE_DETAIL=full` を設定した場合のみ、コマンド先頭 60 文字や検索語も送ります。サーバーはメモリ上にしか保持せず、再起動で消えます。

## テスト

```bash
npm test   # 状態遷移・認可・SSE・静的配信の制限
```

## 既知の制限

- 状態はサーバーのメモリ上のみ（再起動すると、次のイベントが来るまで空に戻る）
- `PostToolUse` は遅延を避けるため送っていない。ツール完了後も、次のイベントまで「作業中」のまま
- 認可は共有トークン方式。複数人で共有する用途には向かない
