# 日曜市内の出店場所

- 出店場所名は郵便住所ではなく日曜市の区画を表す。既存の区画に任意の名前を設定する。既存のデータからは推測せず初期値は未設定とする。
- 場所の名前と地図上の位置は区画に一元化し、同じ名前で別の区画を作れない。店舗は同じ場所を複数登録できる。
- 他の店舗がすでに登録した場所を使う際は、確認してから登録する。
- 現場登録とマップ編集は共通の区画を参照し、その区画に登録されている店舗を確認できる。

## 運用上の境界

- 場所名と座標は `market_locations` に置き、店舗の場所への参照と最新の地図配置を基に、登録店舗を管理画面に表示する。場所の名前は全角・半角と空白の違いを正規化して重複を拒否する。
- 場所が登録済みの店舗は現場で独立した位置・丁目を保存できない。マップ編集で共通区画の位置を変えると、紐づいた店舗の位置が揃って変わる。
- 既存の出店場所名・参照は埋めない。店舗名を解析しての移行は行わない。
- 名前付きの出店場所をまだ登録していない店舗の現場位置は、記録しただけでは地図へ反映されない。マップ編集で区画と店舗を選び、記録日時・座標・誤差・店番を確認して編集内容に追加し、変更を保存すると反映される。記録した店番が区画と違う場合は注意を表示する。道との紐づけは解除される。
- 出店場所への登録と、特定日の公開マップ上の出店配置は別の情報。複数店舗を場所に登録しても、それだけで全店舗が公開マップに出るわけではない。
- 既存の地図配置と異なる区画への登録や、地図配置が残ったまま場所だけ解除することはできない。先にマップ編集で配置を確認・解除する。
- 名前付きの区画は誤削除を防ぐため、現在のマップ編集画面からは削除できない。場所名の修正は関連する全店舗への影響を確認して行う。場所の廃止は未対応。
- 表記揺れの自動同定は全角・半角、大小文字、空白に限る。「一丁目」と「1丁目」などの別表記が同じ場所かは自動判定しないため、既存の区画を検索・選択する。
- 既存のマップ配置だけを持つ店舗がいる区画を命名するときは確認し、その店舗にも同じ区画を紐づける。これにより、その後公開配置を変更しても登録済みの出店場所が消えない。
- 名前付き区画に新しい店舗を配置する前に、現場登録でその店舗を同じ出店場所に紐づける。マップ編集のドラッグやCSV置換で場所の紐付けを黙って変更しない。
