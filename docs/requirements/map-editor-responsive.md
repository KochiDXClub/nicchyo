# マップ編集画面の操作

- PC では地図の右に詳細・編集履歴を表示する。モバイルでは詳細パネルを開閉し、閉じた状態で地図を操作できる。
- マップ編集画面は場所を管理する。店舗情報の登録・編集は現場登録や出店者自身が行う。
- 現在の配置は参照できるが、日付を指定しない店舗の移動・入れ替えはしない。場所ごとの予定管理は別途実装する。
- タッチ画面ではピン上からの地図移動を妨げない。道の頂点はタップで削除メニューを開ける。
- モバイルでは地図の回転ボタンを表示せず、二本指のジェスチャーで回転する。PC では回転ボタンを利用できる。
- 保存履歴、元に戻す・やり直す、区画一覧は画面幅にかかわらず利用できる。
