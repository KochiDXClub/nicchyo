# マップ編集画面の操作

- PC では地図の右に詳細・編集履歴を表示する。モバイルでは詳細パネルを開閉し、閉じた状態で地図を操作できる。
- 店舗のいる名前なし区画は、詳細の「移動先の区画を選ぶ」から地図上の別区画を選択して移動できる。移動先に店舗がある場合は確認のうえ入れ替える。編集は保存操作まで公開されない。
- 名前付き出店場所に紐づく区画は、場所の整合性を保つためこの移動操作では移せない。
- タッチ画面ではピン上からの地図移動を妨げない。道の頂点はタップで削除メニューを開ける。
- モバイルでは地図の回転ボタンを表示せず、二本指のジェスチャーで回転する。PC では回転ボタンを利用できる。
- 既存の検索、道具、CSV取り込み、保存履歴、元に戻す・やり直す、区画一覧は画面幅にかかわらず利用できる。
