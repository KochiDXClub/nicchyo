# 出店場所と出店予定（公開連携は未完了）

- 日曜市の住所は `512` や `183-1` のように、本番号と必要な枝番で表す。場所には内部IDを使用し、住所の表記を店舗のIDにしない。
- 同じ店舗は複数の場所に紐づけられ、同じ場所には複数の店舗を紐づけられる。場所内の店舗番号は住所の枝番とは別に保存する。紐づけ前の店舗に番号はない。
- 場所内の店舗番号は登録時に場所ごとに自動採番し、出店終了後も他店へ再利用しない。同時登録でも一意性を守る。出店終了・再開の期間を残し、同じ店舗が戻っても番号を変えない。
- 繰り返しの規則は登録期間に紐づく。出店が終了すると予定を出さず、再開しても前回の繰り返しを自動で復活させない。
- 予定の規則は毎週、基準日から隔週、第1〜第5日曜を区別する。特定日の出店・休みは規則に優先し、未設定と休みを区別する。異なる店舗の規則が同じ場所・日付に重なった場合は競合として返す。
- 出店予定管理では場所別と店舗別に直近の予定を確認し、登録・終了・繰り返し・特定日の例外を管理する。現場登録は店舗の出店先を表示し、同じ予定管理へ移動できる。
- 旧登録や旧配置は確認用として表示する。開始日や繰り返しを推測して自動移行しない。
- マップ保存・スナップショット復元は地図の状態だけを変更し、日付別の配置履歴を変更しない。履歴のある場所を消す操作は拒否し、保存と配置への同時書き込みを直列化する。旧画面からの店舗情報・日付なしの配置変更は拒否する。
- 旧単一場所APIによる上書きは拒否し、現場観測は自動で地図に反映しない。旧データの移行確認が完了するまでは新しい予定データを公開マップへ接続しない。
- 公開マップの店舗IDは現在は場所番号で、お気に入りと共有URLも参照する。店舗が入れ替わっても別店舗のお気に入りやURLにならない識別子・移行を実装するまで、予定の公開切り替えを提供しない。
- 管理画面の予定表示は開催カレンダーの中止・休みも参照する。公開連携時も開催状況と予定の競合を安全に扱う。
