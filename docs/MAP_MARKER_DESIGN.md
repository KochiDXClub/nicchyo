# マップ店舗マーカー デザイン方針

日曜市マップの店舗マーカーを、拡大倍率ごとに何をどう見せるか決めた方針。
実装の構成そのものは `docs/ARCHITECTURE_SHOP_MARKERS.md` を参照。
以下の DOM・CSS クラスに関する記述は Leaflet 版（`OptimizedShopLayerWithClustering`）のもの。MapLibre 版（`components/maplibre/`）は同じ見せ方の方針を、スプライト（`stallSprites.ts`）とシンボルレイヤー（`shopFeatures.ts`）で実現している。

## 前提としている考え方

`docs/CONCEPT.md` と `docs/map-spec.md`（「情報の詰め込みすぎを避ける」「穏やかなアニメーション」）より:

- 一般的な観光マップの「探す・比較する・決める」ではなく、**不安や緊張を和らげる**ことに集中する
- 情報の詰め込みすぎを避ける
- ピンやバナーの出現は急かさない穏やかなアニメーション

マーカー設計としてはこれを次のように読み替えている。

- **一度に見せる情報を、そのズームで本当に必要なものだけに絞る**
- **近づくほど情報が増える**。逆転させない（かつて木札が出ると全バッジが消えていた）
- **断定しない**。確度の低い情報を見た目で押し付けない

## ズーム段階（LOD）

段階の境界は絶対ズーム値ではなく `map.getMaxZoom()` からのオフセットで持つ。
メインマップ（maxZoom 21）と `map-edit` プレビュー（maxZoom 20）で
同じ4段階を成立させるため。定義は `config/displayConfig.ts`。

| 段階 | オフセット | 出すもの | その倍率で答えたい問い |
|---|---|---|---|
| `dot` | 〜 max-2.0 | 簡易アイコン、お気に入り | 店があるのはどのへんか |
| `stall` | max-2.0 〜 | 屋台（カテゴリ色） | どんな店が並んでいるか |
| `photo` | max-1.4 〜 | ＋ 商品写真（丸窓）、お気に入り | 何を売っていそうか |
| `nameplate` | max-0.8 〜 | ＋ 木札（店名） | どの店か特定する |

メインマップに当てはめると `dot` 〜19.0 / `stall` 19.0〜19.6 /
`photo` 19.6〜20.2 / `nameplate` 20.2〜21.0。

段階の手前には丁目バッジ（`ChomeAreaMarkers`）の帯がある。

### 倍率

`getShopMarkerScale()` は maxZoom で 1.0、maxZoom-2.0 で 0.6 の線形補間。
0.05 刻みに量子化して DOM への書き込みを抑えている。

かつては 0.6 / 0.8 / 1.0 の3段の階段で、さらに 19.7〜19.8 の帯だけ ×1.1 という
根拠のない突起があり、ズームするとマーカーが飛んで見えていた。

### DOM の作り直しを1境界に閉じる

`stall` / `photo` / `nameplate` は**同じ DOM を共有**し、何を見せるかは
ルート要素の `.shop-lod-*` クラスで切り替える。木札も写真アイコンも
DOM としては常に存在する。

`marker.setIcon()`（300店舗ぶんの DOM 作り直し）が走るのは
`dot` ↔ それ以外の1境界だけ。

## カテゴリの色

屋台の色でカテゴリを表す。定義は `config/shopCategories.ts`。

| カテゴリ | 色 | |
|---|---|---|
| 食材 | `#5FA86B` | あさぎ緑 |
| 食べ物 | `#E08A3C` | 柿色 |
| 道具・工具 | `#6B7F9E` | 藍鼠 |
| 生活雑貨 | `#9384B8` | 藤 |
| 植物・苗 | `#4FA58F` | 若竹 |
| アクセサリー | `#D97A9A` | 撫子 |
| 手作り・工芸 | `#C29144` | 黄土 |
| （未分類） | `#B08B5E` | |

サイトの amber / orange 基調に合わせ、彩度を抑えた暖色寄りで揃えている。
色相は隣り合っても弁別できるよう分散させつつ、明度を揃えて
「どれか1色だけが目立つ」ことを避けている。

色の優先順位は **出店者の個別指定（DB） > カテゴリ色 > デフォルト**。
`resolveStallColors()` の1関数に閉じ込めてある。

### 状態色との優先順位

選択 / AI提案 / 検索ヒットの状態色は、カテゴリ色より常に優先する。カテゴリ色は
`.shop-marker-container` に `style="--stall-color:…"` で入り、状態色は CSS（`globals.css` の
`.shop-marker-selected` など）が屋根・庇のクラスに対して直接上書きする。

**カテゴリ色の変数はイラスト div ではなくコンテナに置く**。状態側の上書きが
継承を遮断しやすく、イラスト自身にインライン指定すると上書きできなくなるため。

## 木札ラベル（店名）

`nameplate` 段階で屋台の下に出る札。

| 項目 | 値 |
|---|---|
| 幅 | 可変。`min-width: 44px` / `max-width: 120px` |
| 高さ | 26px（border 込み 28px） |
| 角丸 | 5px |
| 背景 | `linear-gradient(180deg, #f6e9d2, #e7d3ae)`（白木〜杉） |
| 縁 | `1px solid rgba(140, 106, 62, 0.45)` |
| 文字 | 11px / 700 / `#4a3826` / 1行省略 |

かつては 220px 幅の横カード（56px の写真＋店名）だった。
店舗間隔の目安は 80px（`SPACING_CONFIG.minPixelsPerShop`）なので、
**常に3倍近く重なっていた**。これが最大の問題だった。

### 重なり対策 — 木札は「道の外側」に出す

**木札を屋台の真下に置いてはいけない。**

実測（zoom 20.5）: 道に沿った方向の屋台の間隔は **67px**、屋台の高さは **54px**。
隙間は 13px しかないので、高さ26px の木札を真下に置くと
**118件中113件が隣の店の屋台に被る**。「木札を出す倍率なら間隔が開いている」
という想定は誤りだった。

一方、道の幅方向には余白がある。そこで北側の店は北へ、南側の店は南へ
木札を逃がす（`.shop-side-north` / `.shop-side-south`）。
これで屋台への被り・木札どうしの重なりとも **0件**になる。

振り分けの向きは「道の外側」であって内側ではない。逆にすると
道を挟んで向かい合う店の木札が道の中央でぶつかる（実測で26件）。

地図の回転は `.shop-marker-container` が打ち消すので、回転しても
木札は道の外側に留まる。

補助として、選択・AI・検索ハイライト中の店は既存の
`setZIndexOffset(1000 / 900)` で必ず前面に来る。

### `iconSize` に木札の分を足さない

木札は `iconSize` の矩形の外（下）にはみ出して描画される。これは意図的。

- `transform-origin: center bottom` の原点が屋台の足元からずれ、
  ズームのたびに屋台が地面から浮いてしまう
- 300店舗ぶんの不可視ヒット領域が、マーカーの隙間での地図ドラッグを妨げる

木札は `pointer-events: auto` を持ち、クリックは `_icon` にバブリングするので、
`iconSize` を広げなくてもタップできる。

## 商品写真は「屋台の丸窓」

`photo` 段階から、屋台イラストの内側に 50px の丸い写真が出る。
木札が道の外側に出るので、写真は**木札と反対側＝道の内側**へ、屋台イラストの
中心から 24px 内側にずらして寄せる。
屋台の中央に被せると屋台の形が読めなくなるので、必ず片側に寄せること。

見立ては**屋台に開いた丸窓から中を覗いている**状態。これを保つための決まり:

- 枠は白い額縁ではなく**屋台と同じ色**（`--stall-color-dark`）。
  額縁色にすると「屋台に貼った写真」になってしまう。
  - **影は窓の内側ではなく外側に落とす**。内側に落とすと写真が暗く汚れて
  見えるだけで奥行きにならない。窓枠が手前にあって屋台の壁に影を
  落としている、という物理に合わせる
- ガラスの光沢は左上から薄く。屋根の陰影と光源を揃えている

## 道の南北

店舗データに `side` フィールドは無いので、`roadConfig.ts` の `getRoadSide()` が
`getNearestPointOnRoad()` と緯度の比較で導出する。
`.shop-side-north` / `.shop-side-south` を DivIcon の `className` に付ける。

木札の縦オフセットのほか、お気に入りバッジと商品写真の左右の向きもこれで振り分ける。

## 未解決（別途検討）

- **ズーム 15.5〜17 に何も出ない帯がある**。丁目バッジの下限
  `OVERVIEW_ZONE_MIN_ZOOM = 17` を下げれば埋まるが、この定数は
  「このへん、なにがある？」ボタンの出現帯も兼ねている（`MapPageClient.tsx`）。
  丁目バッジ用の定数を分離するのが正しい直し方
- **ジャンルフィルターにカテゴリ色が反映されていない**。
  `MapPageClient.tsx` のチップは全て amber 一色で、マップ上の屋台の色と
  照合できない。色ドットを添えると対応が取れる
