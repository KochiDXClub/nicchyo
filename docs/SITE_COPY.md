# サイト文言の管理

FAQ・紹介ページ・マップ案内・トップページの文言は管理画面の「サイト文言」から編集します。保存した下書きは来訪者には表示されません。「公開前の差分を確認」で内容を確かめ、公開を押すとサイトに反映されます。

公開版はサーバーで最大1時間キャッシュされます。公開した直後は、キャッシュを即座に捨てるため新しい版に差し替わります（他の人の開いている画面は次の読み込みで反映）。来訪者のページは、公開版を読むためにデータベースへ毎回問い合わせません。

公開履歴から以前の版を編集欄に読み込み、差分を確認して公開し直せます。コードの初期値に戻す場合も同じ手順です。公開履歴には日時と操作した管理者のIDを保存します。複数の管理者が同時に編集した場合、先に保存された変更を上書きせず、後からの保存を拒否します。

英語（English）の文言は、管理画面の上部で「English」を選んで編集します。英訳は、書いたときの日本語の原文と一緒に保存します。日本語を後から変えると、その英訳は使われず英語ページでも日本語が出ます（古い英訳を出さないため）。英訳を直すと再び英語になります。「この区分の日本語をAIで英訳」は入力欄に訳案を入れるだけで、確認・手直ししてから下書き保存か公開で保存します。英語の欄を空にすると英訳を消し、初期の英訳（`content/i18n/en.json`）か日本語を表示します。質問と回答（FAQ項目）の英訳は今後の対応です。FAQは既存の質問と回答を日本語で編集できます。コードに直接書かれた文言（`texts.json` に無いもの）は対象外です。

保存と公開は管理者APIで認証・認可し、オリジンと入力内容を検証します。文言はHTMLとして実行しません。DBのテーブルには一般ユーザーからの直接アクセス権を与えていません。

## 導入とデータ

`supabase/migrations/20261105120000_site_copy_cms.sql` をプレビュー・本番それぞれのDBに適用してから使用してください。スプレッドシートから取り込まれた既存の `content/site-copy/` が初期値です。既存データを移行するためのシートへの書き込みは不要です。DBが未設定・移行前・読取不能のときはコードの初期値を表示し、管理画面の保存はできません。

CMSの公開済みデータはSupabaseに保存します。スプレッドシートからGitHubへの定期取り込みは停止しています。旧ワークフローは手動で実行できますが、コード側の初期値を変更するものであり、CMSの公開済みデータは変更しません。通常の編集には管理画面を使用してください。

新しい文言をコードに追加する際は `content/site-copy/texts.json` にキーと初期値を追加し、コードから参照してください。サーバーコンポーネントは `await getSiteText()`（`lib/i18n/server.ts`）、クライアントは `useSiteText()` を使うと公開版が読まれます（`siteTextFor` を使う場合は第3引数に `getPublishedSiteCopy()` の `texts` を渡す）。管理画面の区分は `app/(public)/admin/site-copy/page.tsx` のキーの頭（`landing.` など）で分かれます。保存済みの公開内容に新しいキーがない場合は、そのキーに限って初期値を使います。
