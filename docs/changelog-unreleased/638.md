- 案内中のカードに目的地の写真を出し、「くわしく」を押すとそのカードが広がって中を見られるようにした (#638)
- スポットのカードから「ここへ寄る」と一覧へのボタンをなくし、案内に集中できるようにした (#638)
- 電停や建物の「ここへ案内」を押すと、そのまま道案内が始まるようにした（これまでは、おでかけサポートが開くだけで案内が始まらなかった） (#638)
- 「おでかけ」を押すと、画面の中央で「お手洗い・休けい・のりもの・目印」から選べるようにした（これまでは画面の下に細い帯が出るだけで、選べるものが画面からはみ出していた） (#638)
- メニューの「おでかけサポート」を押すと、別のページに移らず、地図の上でそのまま種類を選べるようにした（種類ごとの件数も添えた） (#638)
