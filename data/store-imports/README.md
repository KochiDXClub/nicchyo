# 住所録の取り込み用 CSV

## 6丁目（紙の住所録の写真から）

`6chome-from-paper-map.csv` は、紙の住所録の「日曜市 6丁目」の写真 2 枚を読み取って作った、
**6丁目の 86 区画**の店番と品目。

- 形式は、地図編集（`/map-edit`）の「住所録 CSV の取り込み」と同じ
  （`本番号, 枝番, 丁目, 側, 店名, 品目, ジャンル`。`app/(public)/map-edit/v3/storeCsvImport.ts`）。
  取り込みと同じパーサー（`parseStoreCsv`）で、エラー 0 件・86 行で読めることを確かめてある。
- **側**は、紙の地図の道の上側を `北`（5xx 番）、下側を `南`（4xx 番）にした
  （取り込みの規則「北・南は住所録の道の上側・下側」と、西＝追手門・高知城が左の向きに合わせた）。
- **店名とジャンルは空**にしてある（紙に店名は載っていないため）。品目は「・」で区切って複数の品目にしてある
  （例: `野生蘭・山野草` → 野生蘭 / 山野草）。
- 「593の2」のような番号は、`本番号=593, 枝番=2` で書いてある。

## 取り込むと何が変わるか

取り込みは、**本番号＋枝番**で区画を探す。

| 番号 | 取り込みの結果 |
|---|---|
| すでにある区画 | 品目があれば置き換える。店名・ジャンルは空なので、いまの値のまま |
| まだ無い番号 | 新しく区画と出店者を作る（店名は `六丁目 北 596` のような仮の名前になる。追手筋の道が必要） |

- 取り込みは地図編集の「変更を保存」で確定する。保存の前に、画面に出る件数と警告を見ること。
- 6丁目だけの CSV なので、**「CSV に無い区画を削除」は選ばない**こと（他の丁目の区画が消える）。

## 読み取りで確かめてほしいこと

写真は 960×1280 で、縦書きの小さな文字を拡大して読んだ。誤読があるかもしれないので、紙で見比べてほしい。

- 紙の上で番号が順番どおりに並んでいない箇所（拡大して、印刷どおりであることは確かめた）:
  `574` が `573` の右、`568` が `561` の右、`499` が `494` と `490` のあいだ
- 店名らしい表記は、そのまま品目に入れてある: `果樹苗木の繁栄農園`（578）
- 紙の版（年度）が写真から分からない。**最新の版かどうかは未確認**

## CSV に入れていない番号

**品目の記載が無い番号**（空き区画か、載っていないだけかは写真からは分からない。入れると、
まだ無い番号は中身の無い区画として新しく作られてしまうので外した）:

- 北: 595, 594, 585, 584, 579, 575, 546, 540, 534, 523の1, 502の1
- 南: 493, 499, 488, 485, 481, 476, 456

**施設**（出店者ではないので外した）: 500 休憩所、501 観光案内所（車いす貸出）
